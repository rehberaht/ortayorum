# Hatıralar ve Yorumlar

GitHub Pages için hazırlanmış reklamsız, statik kişisel blog şablonu.

## Kullanım

`index.html` dosyasını tarayıcıda açarak önizleyebilirsin. GitHub'a yüklemek için bu klasörün içeriğini bir depoya ekle. GitHub Pages ayarlarında `main` dalını ve kök klasörü seçtiğinde site yayınlanır.

Sayfa tek bir HTML dosyasından oluşur; CSS ve JavaScript dosyanın içine gömülüdür. İnternet bağlantısı veya derleme adımı gerektirmez. Abonelik formu görsel bir demodur ve veri göndermez. Yazı bağlantıları örnek içerik noktalarıdır; gerçek yazı sayfaları eklendikçe güncellenebilir.
